# Melate Forecaster

Sistema modular para análisis, modelado y generación de combinaciones del Melate.

## ⚠️ Descargo de responsabilidad

**El Melate es un sorteo aleatorio.** Ningún modelo puede predecir los números.
Este proyecto tiene fines educativos. El objetivo real es:

1. Detectar sesgos físicos en la máquina (si existen).
2. Generar combinaciones estadísticamente balanceadas.
3. **Maximizar el premio esperado** evitando combinaciones populares.
